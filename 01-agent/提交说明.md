## 作业提交文案

**作品名称：** 分数除法习题 学伴智能体

**教育场景：** 六年级数学，只针对「分数除法」一个知识点。学生可以问概念和方法，也可以输入题目和学生答案，请学伴批改。

**技术实现：** GitHub Pages 学伴智能体，采用“精确核算 + 免费免登录大模型”的混合方式。分数除法题、学生答案、知识点问题和使用帮助由本地规则生成可靠结果，不允许模型改写数字或沿用上一题；其他自然语言表达由大模型处理。输入题目时给出正确答案、对错判断、算理和掌握分析。

**Agent 链接：** https://hopehou666.github.io/AI_zuoye/01-agent/agent.html

**演示：**
1. 问：分数除以整数怎么算？
2. 说：4/7 ÷ 3，我写 12/7（应判错，正确答案 4/21）
3. 说：3/4 ÷ 1/2，我写 3/2（应判对）
