# 扣子（Coze）搭建步骤

也可在豆包 APP 创建同类智能体：把 `系统提示词.md` 全文粘贴到人设即可，开场白用 `开场白与示例对话.md` 中的文案。

## 一、创建 Bot

1. 打开 [扣子](https://www.coze.cn/) 并登录。  
2. 点击「创建 Bot」→ 选择「从空白创建」。  
3. 名称建议：`错题诊断与个性化复习助手`  
4. 简介建议：`针对错题定位知识点与错因，引导订正，并生成巩固题与 3 天复习计划。`  
5. 图标可自选教育相关图片。

## 二、配置人设

1. 进入 Bot 编排页，找到「人设与回复逻辑」或「提示词」编辑区。  
2. 打开本目录 `系统提示词.md`，复制「---」下方的全文粘贴进去。  
3. 在「开场白」中粘贴 `开场白与示例对话.md` 里的开场白。  
4. 模型建议选用当前空间可用的对话模型（如豆包系列）；温度偏低（约 0.3～0.5）更稳定。

## 三、可选增强（非必须）

- 关闭不必要的插件，避免答非所问。  
- 若平台支持「用户问题建议」，可加：  
  - `帮我分析一道数学错题`  
  - `我订正过了，只要知识点讲解`  
  - `根据这道错题给我 3 天复习计划`

## 四、调试

用 `开场白与示例对话.md` 中 3 组示例各测一遍，确认：

- 会追问缺失信息  
- 固定输出结构完整  
- 不直接甩答案（默认模式）

## 五、发布与复制链接

1. 点击「发布」→ 选择「Bot 商店」或「复制链接 / 网页 SDK」等可分享渠道（以当前扣子界面为准）。  
2. 将可访问链接粘贴到本目录 `提交说明.md` 的「Agent 链接」处。  
3. 作业提交时附上：链接 + 提示词（可附 `系统提示词.md` 或摘录）。

## 豆包 APP 简要路径

1. 打开豆包 → 创建智能体 / AI 伙伴。  
2. 粘贴系统提示词与开场白。  
3. 分享得到链接后填入 `提交说明.md`。
