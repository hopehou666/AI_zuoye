# 错题诊断与个性化复习助手（教育场景 AI 三件套）

## 统一场景

学生订正作业时往往只看正确答案，难以定位薄弱知识点；教师也难以及时给出个性化复习建议。本作业围绕同一痛点，用三条技术路线分别交付：

| 路径 | 目录 | 交付物 | 使用者 |
|------|------|--------|--------|
| 路径1 智能体 | [01-智能体](./01-智能体/) | 扣子/豆包 Agent + 提示词 | 学生自助诊断 |
| 路径2 多维表 | [02-多维表](./02-多维表/) | 多维表结构 + AI 字段 | 教师班级学情管理 |
| 路径3 交互网页 | [03-交互网页](./03-交互网页/) | `index.html` 单文件 | 课堂/课后即时练习 |

## 与评价指标对齐

- **教育场景适配度**：错题 → 知识点 → 错因 → 巩固题 → 复习计划，贴近真实教与学流程。
- **技术实现可靠性**：固定输出结构、缺信息先追问、超纲降难度，便于反复测试稳定复现。
- **应用角度创新性**：按学段/学科/错因做个性化路径，而非通用闲聊问答。
