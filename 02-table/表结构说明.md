# 多维表结构说明

表名建议：`班级错题诊断库`

用途：教师录入学生错题原文与作答后，由 **AI 字段**自动生成知识点、错因、难度、复习建议与巩固题，形成可筛选的班级学情库。

## 字段一览

| 字段名 | 类型 | AI 字段 | 说明 |
|--------|------|---------|------|
| 记录ID | 自动编号 / 文本 | 否 | 可选，便于引用 |
| 学生姓名 | 文本 | 否 | 可匿名为学号 |
| 班级 | 单选 / 文本 | 否 | 如：初一(3)班 |
| 年级 | 单选 | 否 | 小学五年级、小学六年级、初一、初二、初三… |
| 学科 | 单选 | 否 | 数学、语文、英语 |
| 错题原文 | 多行文本 | 否 | 题目全文（含选项） |
| 学生作答 | 多行文本 | 否 | 学生当时的答案或做法 |
| 录入日期 | 日期 | 否 | 默认今天 |
| 知识点标签 | 文本 | **是** | AI 根据错题生成 |
| 错因类型 | 单选（也可文本） | **是** | 概念理解 / 计算失误 / 审题不清 / 方法选择 |
| 难度估计 | 单选 | **是** | 易 / 中 / 难 |
| 个性化复习建议 | 多行文本 | **是** | 面向该生的短建议 |
| 巩固题生成 | 多行文本 | **是** | 生成 2 道同类题 |

## 字段联动关系

```text
输入列：年级 + 学科 + 错题原文 + 学生作答
        ↓
AI 列：知识点标签、错因类型、难度估计、个性化复习建议、巩固题生成
```

各 AI 字段提示词见 `AI字段提示词.md`。引用其他列时，在飞书多维表 AI 字段配置里选择对应字段变量（名称需与上表一致）。

## 建议视图

1. **全部错题**：表格默认视图  
2. **按知识点**：分组字段 = 知识点标签  
3. **高频错因**：分组字段 = 错因类型  
4. **待复习**：筛选「个性化复习建议」不为空  

## 权限建议

- 教师：可编辑全部字段  
- 学生/家长（若分享）：仅可查看本人相关视图，或只读整表演示版
